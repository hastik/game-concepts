# Random Shooter

Neonový arcade protokol: zaměř, střílej, přitahuj gravitací a vypaluj laser. Aréna roste s vlnou, shop nabízí upgrady a stavby.

## Ovládání

- **Myš** — zaměřovač
- **LMB** — střelba
- **RMB** — gravitace
- **MMB** — laser
- **LMB+RMB** — rázová vlna (freeze)
- **RMB+MMB** — laserová vlna
- **CTRL + kolečko** — dočasný zoom
