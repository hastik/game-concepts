# Sensible Handball (v1)

Top-down házenkářský prototyp inspirovaný Sensible Soccer. ES moduly (`src/`), běží přes HTTP (GitHub Pages).

## Ovládání

- **Šipky** — pohyb
- **Shift** — sprint
- **S** — blízká přihrávka / přepnutí
- **A** — vzdálená přihrávka
- **D** — střela / tackle
- **R** — restart

Zdroj: Dropbox `dev/gamestudio/sensiblehandball/v1`.
