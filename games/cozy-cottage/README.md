# Útulná chaloupka (Cozy Cottage)

Relaxační pixel-art hra v útulné chaloupce. Procházej se, zapal krb, přepínej den a noc a zařizuj interiér nábytkem a svíčkami. Kočka se toulá a spí v pelíšku.

## Ovládání

- **WASD / šipky** – chůze
- **E** – režim zařizování
- **N** – přepínání den/noc

## Status

Prototyp (2026-10-29)
